## Original brief (Norwegian)

These files are the product owner's original planning documents. They are kept in Norwegian as the source the project was built from (#175). [PRD.md](PRD.md) is the English summary of the requirements, and every later change is in [DECISIONS.md](DECISIONS.md).

| [SVAR_PLAN.md](SVAR_PLAN.md) | The product owner's answers to the questions before phase 1 |
| [SVAR_DELMAL_E.md](SVAR_DELMAL_E.md) | The product owner's answers before milestone E (planner rules) |
